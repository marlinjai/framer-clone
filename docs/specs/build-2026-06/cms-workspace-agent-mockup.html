1
Collections navigator

A real left rail: Collections / Fields / Bindings tabs, item counts, groups (e.g. Marketing) and sub-collections (Categories), plus +/sort/filter/search. You actually see and switch between all your content types.

2
Rich items table

Drag-reorder handles, checkboxes, inline cover thumbnails, colored status pills, and a Featured toggle. Hover any row to “Add to agent” so you can act on specific items.

3
Content agent

The differentiator: import a CSV, generate posts, translate, bulk-publish, or edit fields in natural language. Shows its plan, applies real changes, and every change is reversible (Undo). Your agent-first thesis, in the CMS.
